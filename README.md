# PLAN2MODEL - public evidence site

Static GitHub Pages source for the EIT Culture & Creativity Spark application (acronym
PLAN2MODEL). Everything here was generated by the Kaiken prototype from **synthetic
example drawings only** - no client drawings, no personal data beyond the applicant's
public contact, no tracking.

## Publish (once a funding window is confirmed)

    cd <this folder>
    git init
    git add -A
    git commit -m "PLAN2MODEL evidence build"
    git remote add origin https://github.com/iavxhiir/plan2model-evidence.git
    git push -u origin main

Then: GitHub repo -> Settings -> Pages -> Deploy from a branch -> `main` / root.
The site appears at `https://iavxhiir.github.io/plan2model-evidence/` (a minute after the
push). Open `index.html` locally first to proofread, and test the live URL in a private
browser window (each viewer page fetches the three.js library from a CDN, so the first
render needs internet). Keep the site online at least until the call results.

## Regenerate

From the application package folder:

    python build\build_site.py

The script runs the prototype (`kaiken view3d`, `kaiken export`) over the four synthetic
examples in the product repository and rewrites `index.html` and `examples\`. It refuses
to read any drawing whose name matches `buildingNNN` (the client examples), and it strips
local file paths from the generated viewer pages.

## Contents

- `index.html` - overview, limits stated honestly, statistics table.
- `examples/<name>/` - `viewer.html` (self-contained 3D page), `model.glb`,
  `quantities.csv`, `parse_summary.txt`, `source.dxf` (the synthetic input),
  `screenshot.png`.
